# EGibson-Probably-Stolen-Mods

Mods for the game **Probably Stolen**. Each mod has its own folder with its own build instructions.

- [50 Appraisal Buttons (+50/-50)](<50 - Appraisal Mod/>): adds +50 and -50 buttons to the appraisal panel.
- [Jerma Rats](JermaRats/): animated rats, custom rat pick-up and put-down sounds, and a crowned Biggest Rat.
